# Маппинг элементов СМО на бизнес-домен

**Домен:** API маркетплейса для маршрутизации заказов по распределительным центрам.  
**Вариант:** 8.  
**Автор исходных материалов:** Марьянков Леонид, группа 5130904/40102.

| Элемент СМО | Сущность домена | Роль в модели |
|---|---|---|
| Источник | Покупатель / класс покупателей маркетплейса | Бесконечный источник заказов (`ИБ`); каждый источник генерирует заявки с независимыми интервалами `ИЗ2`. |
| Заявка | Заказ покупателя | Единица работы с ID, источником и временными отметками генерации, начала и окончания обслуживания. |
| Буфер | Общая очередь маршрутизации API-шлюза | Хранит заказы, ожидающие назначения в центр; постановка в хвост в порядке поступления (`Д1ОЗ2`). |
| Прибор | Распределительный центр / склад-исполнитель | Комплектует и отправляет один заказ; время обслуживания соответствует `ПЗ1`. |
| Диспетчер постановки | Модуль маршрутизации API-шлюза | Принимает сгенерированный заказ и применяет правила буферизации и переполнения. По классической схеме не выбирает и не проверяет приборы. |
| Переполнение очереди | Последняя заявка, уже находящаяся в буфере | При полном буфере последняя ожидающая заявка вытесняется и учитывается как отказ; новый заказ занимает освободившееся место. Остальные заявки не меняют порядок. |
| Диспетчер выбора | Планировщик назначения заказов | По триггеру выбирает одну заявку с приоритетом источника (`Д2Б4`), затем назначает её на свободный центр по кольцу (`Д2П2`). |
| Обслуживание | Комплектация и отправка заказа | Начинается при назначении на свободный центр, заканчивается событием `ServiceCompleted`. |
| Выход | Обслуженный либо вытесненный заказ | Обслуженный заказ покидает систему после комплектации; вытесненный заказ учитывается как отказ. |
| Отображение динамики | Формализованная схема и текущее состояние (`ОД2`) | Пошаговый просмотр состояния буфера, центров, указателя и статистики. |
| Отображение результатов | Сводная таблица (`ОР1`) | Итоговая статистика без графиков по формуле варианта. |
