# Диаграммы

- `sequence-main.puml` — основной сценарий с альтернативами.
- `sequence-happy-flow.puml` — прямой сценарий, когда очередь и центр доступны.
- `sequence-overflow-d1oo4.puml` — переполнение очереди и вытеснение последней ожидающей заявки.
- `sequence-buffer-wait-and-dispatch.puml` — постановка, ожидание, выбор заявки и назначение центра.
- `class-diagram.puml` — поля, методы и связи компонентов.
- `flowchart-swimlanes.puml` — блок-схема с дорожками.
